Privacy Policy

Calendar Dot · Effective 7 October 2026

Summary

Calendar Dot is a personal, non-commercial assistant used only by its developer, Can Zagnos. It runs on the developer's own computer. It reads the developer's own Google Calendar and, only after the owner's explicit approval, changes that calendar or sends an email from the owner's Gmail account. Calendar Dot has no servers of its own and does not sell, rent or advertise with any data.

Google user data that Calendar Dot accesses

  • Account identity: the Google account ID, email address and name, used to confirm which account is signed in.
  • Google Calendar events on the primary calendar: title, start and end time, location, organizer, attendees and their responses, meeting link and status.
  • Gmail: sending only. Calendar Dot sends plain-text emails the owner approved. It does not read, search, label or delete any email.

How the data is used

  • To detect changes to upcoming meetings and notify the owner on WhatsApp.
  • To answer the owner's questions about their calendar.
  • To carry out an action the owner approved on WhatsApp with a one-time code: answering an invitation, cancelling or moving a meeting the owner organizes, creating a meeting, or sending an email. Recipients are limited to an allowlist the owner configures.

The data is used for no other purpose.

Where the data is stored

Only on the owner's computer:

  • A local database holds calendar snapshots, the changes detected, records of the assistant's work, the WhatsApp conversation with the owner and an audit log of approved actions.
  • The Google sign-in tokens are stored encrypted with the operating system's credential store (macOS Keychain).

Who the data is shared with

Calendar Dot shares data only with the services it needs to work for the owner:

  • OpenAI (the AI model provider): calendar information relevant to a request is sent to OpenAI's API so that the model can decide whether a change matters and write the reply.
  • Twilio (WhatsApp delivery): messages between Calendar Dot and the owner's own WhatsApp number pass through Twilio. They can mention the owner's meetings, for example a changed time.

Data is never shared with anyone else, never used for advertising and never sold. Calendar Dot does not use Google user data to develop, improve or train generalized AI or machine-learning models.

Limited Use

Calendar Dot's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

  • Local data is kept until the owner deletes it. Deleting Calendar Dot's data folder removes it.
  • Signing out (logout) deletes the stored Google tokens.
  • Access can be revoked at any time at myaccount.google.com/connections. Calendar Dot then can no longer read or change anything.

Changes and contact

If this policy changes, this page is updated and its effective date changes. Questions: github.com/czagnos.
